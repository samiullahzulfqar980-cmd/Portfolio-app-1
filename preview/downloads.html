Run it in two minutes

  1. Unzip the archive and cd portfolio_app.
  2. Install Flutter 3.24+ and run flutter pub get.
  3. Copy .env.example to .env and add your Supabase URL + anon key.
  4. flutter run on a phone, or flutter run -d chrome --dart-define-from-file=.env.
  5. In Supabase: run the three files in supabase/migrations/ in order, then supabase/seed.sql.
  6. Grant admin: insert your auth user into public.admin_users (see README).

Without the Supabase keys the app runs in preview mode with the bundled sample content — that is the only case where sample data is shown. With keys configured, every profile, project, skill, service, timeline entry, inquiry and file comes from Supabase.
